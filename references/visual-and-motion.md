# 视觉、动效与交互语法

## 精确排版

安装/捆绑可用且许可合适的中文无衬线字体，渲染前检查真实加载，避免隐式回退导致宽度抖动。层级靠尺寸、字重、间距和留白建立；不要每句都最粗、最大、发光。不要未经请求重新画品牌 Logo。

同级功能框字体统一。用最长标签核算空间，先调整组宽、间距或整体字号；不要仅把长标签缩小。英文扩展后重新排版，品牌名可保留，其余界面和标签按确认的语言一致。保留用户准确措辞；疑似错字在脚本阶段指出，不擅自替换已经确认的名称。

本系列输入特写的参考值：1920×1080 画布中，居中输入框约 1500×240，内边距 28×30，中文主输入字号 56，辅助控件约14–16。这是历史批准的特写比例，不用于整页表格正文。长句先验证能完整显示，不横向压扁；输入光标高度和文本匹配。

辅助步骤条应小于被演示主体，放入安全留白，不覆盖节点标题。每行左右边缘对齐；标题框总宽等于下方步骤总宽时，从统一布局 token 推导。位移修改作用于整组节点、标签、连接线和鼠标坐标，不能只移卡片。

## 背景与内容融合

冰川蓝仅在延续系列时作为起点：深海军蓝向冷青蓝渐变、低对比网格、少量柔光。Agent 侧栏采用同色相深蓝黑半透明表面与柔和边界过渡；正文保持对比，不让网格穿透干扰阅读。不要用突兀黑块分割两侧。

画布角标使用浅色半透明填充、细冷色边框。鎏金边框适合已确认的品牌功能卡，不自动加到所有操作提示。Data 状态色区分普通强调、临界、超额；颜色必须服务含义，不能多个无关色同时抢焦点。

## 素材比例

先区分播放器外框、源文件内嵌黑边和截图查看器的灰边。源图片黑边需定点裁切，保留人物和重点；框内用合适的 cover/contain，保持宽高比。不能简单拉伸填满。影片本身有意义的宽银幕构图不能无判断裁掉。

无限画布可以有密度、大小差异和不规则簇，使用不同内容节点；不能重复少数图片伪装素材丰富。将后面才生成的节点从开场全景隐藏，为连续推进预留空白区域。转入空白时保持背景位置、缩放基准与下一段一致。

## 交互因果

为一次操作显式定义：
`ready → moveStart → arrive → press → release → resultStart → complete`。

指针采用稳定白色箭头（细暗描边/轻阴影），以尖端为坐标锚点。鼠标到达按钮后短暂停顿，轻按/小圆环只在点击时出现，随后消退。不要用“➤”字符代替鼠标，更不能点在“智能排序”却声称点击“生成全部角色”。布局缩放/镜头变换后仍要检查实际屏幕坐标。

结果出现在释放后或产品真实响应时。按钮点击只触发一次；开始生成前不能提前出现图片、上传前不能出现封面、生成未完成不能显示完成标记。用独立变量表示设定总数、已处理批次、图片生成数，三者不能共用一个进度。

Agent 流式输出按用户提供内容及顺序呈现。自动滚动追随新增内容而非整页上下漂浮。长内容可加速展示，但可见区域保持真实排版、任务标题与当前状态，不能随意换成摘要卡。

## 选择视觉引导

| 任务 | 优先手段 | 避免 |
|---|---|---|
| 指示一次按钮操作 | 鼠标移动+短促点击反馈 | 长驻大箭头、与按钮不相干的大字幕 |
| 解释预算/成员/警报 | 目标细边框呼吸+近旁短提示 | 跨栏连线、多层重复框、整屏闪烁 |
| 展示 Agent 自动工作 | 文本新增、状态变化、自然滚动 | 假造确认按钮、每行强加指引 |
| 章节进度 | 小型常驻标题+当前步骤高亮 | 大标题遮盖素材；预先高亮未来步骤 |

呼吸仅作用于边框/光晕，文字主体保持可读；参考 1.2–1.6 秒一轮，两轮后稳定。每次只有一个主要焦点，状态提醒有语义关联时可同步高亮区域和提示文案。

## 品牌与转场

保留已批准的品牌字标描边绘制、组装或模糊渐入，新增功能卡不能把它换成静态字。功能卡依次入场；收束时其他卡快速离场，保留卡同时移动到中心，不分成两个停顿动作。同级字号一致。

短标签入场参考 0.25–0.45 秒，错峰0.15–0.3秒，离场0.2–0.35秒；按品牌克制度调整。多字标签不是每个字都弹跳。稳定段绝不给正文叠加循环 sin 位移。

转场优先连续对象、匹配构图或叠化：画布节点放大成播放器；点击作品卡弹详情后叠化到品牌；项目卡保持身份进入另一平台。相邻镜头背景、物体位置、尺寸、运动方向和透明度要接得上。避免非设计黑场、突然重置、重复Logo、还没完整显现就截断。
