# 最终质量检查

## 视觉检查

- 在目标显示尺寸检查整片，至少查看开场、每类布局、最长文案、关键状态和末帧，不只看缩略图。
- 文字无错字、语言混用、切边、变形、无意义抖动、模糊重影；同级功能标签字号一致。
- UI 信息密度合理，关键动作能一眼识别，实际内容不像空壳；不杜撰菜单或功能。
- 图片/视频无意外黑框、拉伸、重复占位；如有创作性黑边能说明原因。
- 提示条、标题、鼠标、弹窗不遮住当前操作与结果，背景两侧融合且文字可读。
- 原有已确认的品牌动效与音轨仍在，没有重复Logo、技术水印、调试标签和红色批注框残留。

## 动态检查（必须来自视频或连续帧）

- 点击段检查 ready / 到达 / 按下 / 释放 / 结果起始及其前后帧。鼠标尖端落在真实按钮范围内；放大或位移后仍正确。
- 前置条件完成后才能点击；点击后才显示加载、生成、保存、封面等结果。自动流程依照真实产品，不添加虚假人工操作。
- 步骤高亮由对应业务状态触发；提示在用户指定时刻退出，不遮挡后续展开内容。
- 进度分母、批次、列表数量和完成文案互相一致，不能进度5/63却显示完成；不同业务进度分别检查。
- 连线随节点同步移动，不重复、不悬空；父子缩放正确。
- 转场首末位置、缩放、背景及音乐连续；检查接缝前后至少约0.3秒，避免短闪、重置、漂移、静帧突然跳动。
- 完整文字/卡片显现后有阅读停顿；结尾有稳定定版。视频不能停在弹入一半。

## 技术检查

用 ffprobe 检查尺寸、fps、时长、音轨；FFmpeg 全片解码检查损坏。实际查看最终编码文件关键段，解码无错只代表文件正常，不代表画面正确。抽帧检查不等于已完整播放，验收记录要诚实区分。

实际听音频，核对首尾、对白与字幕、点击音、音量、无爆音与截断；无声片确认无声是预期。字幕不超安全区、不泄露真实敏感演示数据。

验收结果记录为 `pass / needs-fix / not-checked`，附对应帧/时间码和文件；有阻塞项先修，再重新检查受影响镜头与相邻接缝。不把“未来可以替换”算作最终完成。
