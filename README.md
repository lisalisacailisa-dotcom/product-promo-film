# 产品宣传片制作 Skill

从产品手册、操作资料、真实界面与参考片提炼可制作的分镜脚本，确认后生成动效和完整成片。

## 安装与使用

将仓库文件放入 ~/.codex/skills/product-promo-film，在 Codex 中调用：

使用 $product-promo-film，根据我提供的产品手册和素材先产出完整分镜脚本，确认后直接制作完整宣传视频。

建议提供：产品手册、受众、时长、语言、Logo、界面截图或参考录屏及已有媒体素材。

## 内容

- [技能入口](SKILL.md)：资料分析、脚本确认、制作与交付流程。
- [分镜模板](assets/script-template.md)：时间线、文案、素材与验收记录。
- references/：视觉动效、产品经验、工程导出、质量检查。
- scripts/check-timeline.mjs：镜头覆盖、交互时序和鼠标落点检查。

检查器需要 Node.js，格式见 [时序说明](references/timeline.md)。视频制作通常需要 Remotion、浏览器、FFmpeg及可用字体，按项目配置。配音与生成式素材依赖运行环境，技能不附带模型服务或密钥。

技能提供制作方法，不保证只凭手册即可还原经核实的真实产品；缺少素材或功能证据应明确说明。时序检查不能替代观看最终视频。

本仓库不含原始对话、账号信息和产品媒体素材。Drama 系列名称仅用于说明经验来源。
